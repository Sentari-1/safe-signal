# SafeSignal

Real-time safety signals for public transport

SafeSignal is a mobile-first platform that enables commuters to report, verify, and receive real-time alerts about safety incidents in public transport systems such as matatus and boda-bodas.

---

## Problem

Public transport commuters frequently face:

- Overcharging and fare disputes  
- Harassment and misconduct  
- Theft and insecurity  
- Unsafe or aggressive crew behavior  
- Road accidents and poor response  

Despite how common these incidents are, most go unreported or are shared informally (e.g. WhatsApp), making them:

- Hard to verify  
- Not actionable  
- Invisible to other commuters  

Existing platforms focus on traffic updates rather than safety and accountability.

---

## Solution

SafeSignal provides a real-time incident reporting and safety intelligence layer for urban mobility.

Users can:
- Submit incident reports with location and description  
- View nearby safety alerts  
- Understand ongoing risks in real time  

The system:
- Aggregates multiple reports  
- Verifies incidents using consensus  
- Converts raw input into trusted safety signals  

---

## Powered by Qwen

Qwen powers the intelligence layer of SafeSignal:

### Report Structuring
Transforms unstructured user input into:
- Incident categories  
- Tags  
- Severity levels  

### Clustering
Groups similar reports into a single incident signal.

### Summarization
Generates clear alerts from multiple reports.

### Prioritization
Ranks incidents based on risk level.

## Core Features (MVP)

- Incident reporting (location + description)  
- AI-powered classification and summarization  
- Real-time incident feed  
- Basic verification (multiple reports = confirmed signal)

## Tech Stack (Planned)

- Frontend: Mobile-first web application

---

## Demo Flow

1. Users submit multiple incident reports  
2. Qwen processes and structures them  
3. Reports are grouped into a single incident  
4. A summarized alert is generated  
5. Users see real-time safety signals
